# Counter circuit 
| Python     |                                              |
|------------|----------------------------------------------|
| **7SEG**   | Counts up to desired value (in this case 10) |
| **Button** | Initianlizes count                           |
| **RGBLED** | Turn blue to red as count goes               |
| **Buzzer** | Beeps once per second                        |
| **Motor**  | Chronometer, goes from 0 to 180 with steps   |
| **Pot**    | Sets the pace of the countdown               |
| **LDR**    | Changes the frequency of beep                |
